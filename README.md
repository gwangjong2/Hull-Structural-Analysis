개략 일반 배치도 
선체 내부 배치를 쉽게 파악할 수 있도록 나타낸 작은 도면
구획과 배치를 정의하기 위한 것으로 주로 기준선을 많이 참조함

상세 일반 배치도
계약 시 첨부되는 배치도로 선실배치 하역장치 게선장치등 상세배치를 포함
선급 규제와 룰에 저촉되는 사항이 없도록 하고 효율적인 배치가 되도록 노력
측면도, 평면도, 중앙단면을 포함하여 전체적인 배치상황을 나타내게 한다

# 선박의 구조와 강도
선박의 구조해석 과정은 비교강도 개념이 적용됨
기존 선박의 실적자료로부터 구조적 안정성이 동등하거나 그 이상이 되도록 설계
새로운 유형의 선박일 경우엔 하중의 통계적 분석과 유한요소법을 사용한 정밀 구조해석 기법을 이용

선박의 요구 강도를 부담하는 선체의 치수들은 선급규칙에 규정됨
더 작은 부재치수를 사용하는 경우엔 최대 흘수를 감소시키지 않으면 안된다

종방향의 힘 
선체의 길이 방향으로 작용하는 힘에 대항하는 강도 - 종강도(longitudinal strength)
선체에서 가장 중요하며 이 때 생기는 응력을 선체 거더 응력이라 함

선체 거더 응력이란 선체를 하나의 커다란 보로 보앗을때 이 배에 발생하는 응력을 말함
이 떄 발생되는 응력은 길이방향 굽힘모멘트 전단력으로 인한 응력 폭방향으로 변형시키는 응력 비틀림 응력 등으로 분류할 수 있다.

횡방향의 힘 
선체의 폭 방향으로 작용하는 힘으로 이에 대항하는 강도 - 횡강도(transverse strength)

국부적인 힘
선체의 어느 한 부분에 작용하는 힘으로 이데 대항하는 강도 - 국부강도(local strengh)
